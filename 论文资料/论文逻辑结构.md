




# 第 1 章 问题建模与任务刻画

## 1.1 电力系统量测与状态估计模型

- 量测与状态关系  
  - 在准稳态假设下，引入标准量测模型
    \[
      \mathbf{y}_t = h(\mathbf{x}_t) + \mathbf{e}_t,\quad \mathbf{e}_t \sim \mathcal{N}(\mathbf{0},\mathbf{R}),
    \]
    其中 \(\mathbf{x}_t \in \mathbb{R}^n\) 为时刻 \(t\) 的系统状态（如节点电压幅值与相角），\(\mathbf{y}_t \in \mathbb{R}^m\) 为对应的量测向量，\(h(\cdot)\) 为非线性量测函数。  
  - 简要说明量测冗余：通常 \(m > n\)，为状态估计与坏数据检测提供冗余信息。

- 传统状态估计与下游应用
  - 回顾加权最小二乘（WLS）状态估计的基本形式，将其视作从量测序列 \(\{\mathbf{y}_t\}\) 到状态序列 \(\{\hat{\mathbf{x}}_t\}\) 的映射 \(\mathcal{S}:\mathbf{y}_{1:T}\mapsto \hat{\mathbf{x}}_{1:T}\)。
  - 说明 WLS 估计结果为潮流分析、预防性控制与调度优化提供统一、一致的状态基准，强调状态估计的中心地位。

## 1.2 FDIA 场景下的受攻击量测

- FDIA 量测模型
  - 在上述量测模型基础上，引入虚假数据注入攻击：
    \[
      \tilde{\mathbf{y}}_t = \mathbf{y}_t + \mathbf{a}_t,
    \]
    其中 \(\mathbf{a}_t\) 为攻击向量。

- 隐蔽性设计
  - 攻击者期望将状态估计偏移 \(\mathbf{c}\)，其攻击构造需满足 \(\mathbf{a}_t = h(\mathbf{x}_t + \mathbf{c}) - h(\mathbf{x}_t)\)，确保篡改后量测在残差统计意义上仍符合正常分布特征。
  - 攻击向量通常受稀疏性约束 \(\|\mathbf{a}_t\|_0 \leq k\) 与可访问集合约束，反映攻击资源限制与对电网基础设施的有限渗透能力。

- 状态估计偏差问题
  - 当满足隐蔽性约束的攻击向量注入后，WLS估计器将收敛至偏移状态，导致下游潮流计算偏离、安全裕度误判乃至经济调度失当。

## 1.3 FDIA 检测与其功能边界

- 传统坏数据检测的局限
  - 经典卡方全局检验建立在残差统计假设之上，对随机坏数据具有一定检测能力，但在针对性构造的 FDIA 下残差统计量可被刻意控制在正常范围内，从而无法给出有效告警。
  - 传统的局部诊断方法（如最大归一化残差法）同样依赖残差结构，在 FDIA 场景下难以区分受攻击量测与正常量测。

- 检测任务的研究现状与功能边界
  - 鉴于传统坏数据检测机制在 FDIA 场景下失效，近年来针对 FDIA 的检测问题已成为独立的研究方向，相关方法能够在时间轴上标记出可能受到攻击影响的可疑时刻集合 \(\mathcal{T}_{\mathrm{att}}\)。
  - 然而，检测的输出是判别性的（"该时刻可能被攻击"），而非生成性的——检测本身不提供受污染量测的替代值。

- 检测后的处理需求
  - 对于 \(t \in \mathcal{T}_{\mathrm{att}}\)，量测 \(\tilde{\mathbf{y}}_t\) 被标记为"可能受攻击"，但并非确定受攻击。
  - 若直接丢弃，将导致量测缺失；若直接使用，可能引入状态偏差。因此需要一种恢复机制，为状态估计提供可用的替代量测。

## 1.4 状态重构任务与量测恢复角色

- 任务背景
  - 由于检测输出的是"可能受攻击"而非"确定受攻击"，恢复机制需同时应对两种情形：被标记的量测可能是真正受攻击的，也可能是正常但被误报的。

- 恢复方法的双重要求
  - 对于正常数据：恢复操作不应破坏原有量测，即当 \(\tilde{\mathbf{y}}_t = \mathbf{y}_t\) 时，应有 \(\hat{\mathbf{y}}_t \approx \mathbf{y}_t\)。
  - 对于攻击数据：恢复操作应将受污染量测拉回正常轨迹，即当 \(\tilde{\mathbf{y}}_t = \mathbf{y}_t + \mathbf{a}_t\) 时，应有 \(\hat{\mathbf{y}}_t \approx \mathbf{y}_t\)。

- 不依赖精准定位
  - 由于诊断方法难以在量测维度上精准定位受攻击分量，恢复算法的设计不应依赖于"哪些量测维度被攻击"的先验信息，而应从整体量测向量出发，利用正常运行轨迹的统计特征进行重构。

- 任务形式化
  - 对于任一 \(t\in\mathcal{T}_{\mathrm{att}}\)，记 \(\tilde{\mathbf{y}}_t\) 为被标记的量测，\(\mathbf{y}_t\) 为理想干净量测。引入量测恢复算子 \(\mathcal{G}\) 与状态估计算子 \(\mathcal{S}\)，任务可形式化为
    \[
      \hat{\mathbf{y}}_t = \mathcal{G}(\tilde{\mathbf{y}}_t),\quad
      \hat{\mathbf{x}}_t = \mathcal{S}(\hat{\mathbf{y}}_t),
    \]
    其中 \(\mathcal{G}\) 为本文研究的基于学习的量测恢复算子，需同时满足上述双重要求；\(\mathcal{S}\) 为既有状态估计模块。

# 第 2 章 基于时序变分自编码器的数据恢复方法

## 2.1 具有状态空间先验的VAE生成模型

- 标准 VAE 的局限
  - 标准 VAE 假设潜在变量在时间上独立同分布，先验为 \(p(\mathbf{z}_{1:T}) = \prod_{t=1}^T \mathcal{N}(\mathbf{z}_t;\mathbf{0},\mathbf{I})\)。
  - 该假设忽略了电力系统运行轨迹在时间上的平滑演化特征，使得模型难以有效利用历史信息对当前受攻击量测进行约束。
  - 虽然部分工作采用LSTM或GRU作为编码器以隐式捕捉时序依赖，但先验分布本身仍为静态独立结构，模型缺乏利用历史信息约束当前时刻恢复的明确概率机制。

- 线性高斯状态空间先验（核心创新）
  - 本文将静态独立高斯先验替换为一阶线性高斯状态空间模型（LGSSM）：
    \[
      \mathbf{z}_1 \sim \mathcal{N}(\mathbf{m}_0,\mathbf{P}_0),\quad
      \mathbf{z}_t \mid \mathbf{z}_{t-1} \sim \mathcal{N}(\mathbf{A}\mathbf{z}_{t-1},\mathbf{Q}),\quad t=2,\dots,T.
    \]
  - 其中 \(\mathbf{A}\) 为状态转移矩阵（施加谱半径约束 \(\rho(\mathbf{A}) < 1\) 保证平稳性），\(\mathbf{Q}\) 为过程噪声协方差（对角加低秩参数化保证正定性）。
  - 完整生成模型：\(p_\theta(\mathbf{z}_{1:T},\mathbf{y}_{1:T}) = p(\mathbf{z}_1)\prod_{t=2}^T p(\mathbf{z}_t\mid \mathbf{z}_{t-1}) \prod_{t=1}^T p_\theta(\mathbf{y}_t\mid \mathbf{z}_t)\)。
  - 这一修改是本文的核心创新：先验显式编码"相邻时刻潜在状态平滑演化"的归纳偏置，为基于历史数据的量测恢复提供概率框架。

- 近似后验与 ELBO
  - 引入因果分解的近似后验 \(q_\phi(\mathbf{z}_{1:T}\mid \tilde{\mathbf{y}}_{1:T}) = \prod_{t=1}^T q_\phi(\mathbf{z}_t\mid \tilde{\mathbf{y}}_{1:t})\)，即时刻 \(t\) 的潜在状态仅依赖历史及当前观测，不使用未来信息。
  - 优化目标为序列级 ELBO，KL项利用先验的马尔可夫结构可逐时间步分解并累积计算。
  - KL项度量后验轨迹与先验预测之间的偏离：当输入受攻击扰动时，异常后验与正常先验预测间的KL散度增大，在优化目标中产生惩罚，从而使模型学习在后验推断中平衡当前观测与历史演化约束。

## 2.2 编码器与解码器结构设计

- 因果性约束
  - 实时部署场景中，恢复模块无法访问未来量测，时刻 \(t\) 的后验参数仅可依赖 \(\tilde{\mathbf{y}}_{1:t}\)。这一因果性约束排除了双向循环网络与完整序列注意力机制。

- 因果时序卷积网络（Causal TCN）
  - 编码器采用因果TCN，通过非对称左填充实现因果膨胀卷积，在每个时间步 \(t\) 仅利用 \(\tilde{\mathbf{y}}_{1:t}\) 提取特征并输出后验参数。
  - 编码器由 \(L\) 个残差块堆叠构成，通过跳跃连接缓解梯度消失，以指数增长的膨胀率在有限层数内覆盖较长历史窗口。
  - 输出层采用Cholesky参数化以刻画完整后验协方差结构。

- 解码器与量测生成
  - 解码器采用多层感知机结构，将 \(\mathbf{z}_t\) 映射至时变高斯似然参数：
    \[
      p_\theta(\mathbf{y}_t\mid \mathbf{z}_t) = \mathcal{N}(\boldsymbol{\mu}_t^{(y)}, \mathrm{diag}(\boldsymbol{\sigma}_t^{2(y)})).
    \]
  - 恢复阶段取条件均值 \(\hat{\mathbf{y}}_t = \boldsymbol{\mu}_t^{(y)}\) 作为输出。

## 2.3 生成式状态重构模型：LGSSM-VAE


  - 本节将2.1节的状态空间先验与2.2节的网络结构整合为完整的生成式状态重构模型
  - **图**：模型由三个核心模块组成——因果TCN编码器、LGSSM潜在空间、MLP解码器（见图X）。

- 数据流描述
  - **输入层**：在时刻 \(t\)，构建长度为 \(K\) 的历史窗口 \(\mathcal{W}_t = \{\tilde{\mathbf{y}}_\tau\}_{\tau=t-K+1}^{t}\) 作为框架输入，其中 \(K\) 不小于TCN的有效感受野。
  - **编码阶段**：历史窗口 \(\mathcal{W}_t\) 经由因果卷积编码器逐时间步提取特征，得到后验分布参数 \((\boldsymbol{\mu}_t, \boldsymbol{\Sigma}_t)\)，即 \(q_\phi(\mathbf{z}_t \mid \tilde{\mathbf{y}}_{t-K+1:t})\)，刻画当前时刻潜在状态的不确定性。
  - **潜在空间演化**：后验分布受LGSSM先验约束，先验通过状态转移 \(\mathbf{z}_t \mid \mathbf{z}_{t-1} \sim \mathcal{N}(\mathbf{A}\mathbf{z}_{t-1}, \mathbf{Q})\) 编码时序平滑性，KL散度项在优化中平衡当前观测与历史演化预测。
  - **解码阶段**：从后验分布采样（或取均值）得到 \(\mathbf{z}_t\)，经MLP解码器输出量测分布参数 \((\boldsymbol{\mu}_t^{(y)}, \boldsymbol{\sigma}_t^{2(y)})\)，最终重构量测 \(\hat{\mathbf{y}}_t = \boldsymbol{\mu}_t^{(y)}\)。

- 数学与网络模块的对应关系
  | 数学符号 | 网络模块 | 功能描述 |
  |---------|---------|---------|
  | \(q_\phi(\mathbf{z}_t \mid \tilde{\mathbf{y}}_{t-K+1:t})\) | 因果TCN编码器 | 从观测序列推断后验分布 |
  | \(p(\mathbf{z}_t \mid \mathbf{z}_{t-1})\) | LGSSM先验 | 编码时序平滑演化约束 |
  | \(p_\theta(\mathbf{y}_t \mid \mathbf{z}_t)\) | MLP解码器 | 从潜在状态生成量测 |

- 核心机制
  - **因果性保证**：TCN的因果卷积和有限感受野确保时刻 \(t\) 的推断仅依赖窗口内的历史量测 \(\tilde{\mathbf{y}}_{t-K+1:t}\)，满足实时部署需求。
  - **鲁棒性来源**：当输入受攻击扰动时，异常后验与先验预测间的KL散度增大，优化目标驱动模型向先验预测方向修正，实现基于历史信息的去噪重构。
  

## 2.4 训练策略 (Training Strategy)

- 训练目标
  - 基于2.3节构建的框架，本节阐述如何通过两阶段策略优化参数 \(\theta\)（解码器与先验参数）和 \(\phi\)（编码器参数）。
  - 损失函数直接源于框架中定义的概率分布：重构项对应解码器似然，KL项对应后验与先验的匹配。

- 训练数据设定
  - 训练仅使用正常运行量测序列，不依赖攻击样本标注。

- 两阶段训练策略
  - **第一阶段：标准ELBO预训练**。以干净量测同时作为编码器输入与重构目标，使模型学习正常运行数据的潜在分布结构，建立对正常轨迹的基准表征能力。
  - **第二阶段：鲁棒训练**。在正常量测上构造模拟受攻击版本 \(\tilde{\mathbf{y}}_{1:T}\)，以其作为编码器输入，以对应干净量测 \(\mathbf{y}_{1:T}\) 作为重构目标。

- 模拟攻击注入机制
  - 采用时空稀疏的Laplace扰动注入：对于每个训练窗口，以概率 \(p_{\mathrm{clean}}\) 保持干净，否则在随机选取的时间段与量测维度子集上叠加扰动。
  - Laplace分布的重尾特性使模拟扰动在幅值分布上更接近实际攻击场景。

- 锚定损失
  - 第二阶段在标准ELBO基础上引入锚定损失项：\(\mathcal{L} = \mathcal{L}_{\mathrm{ELBO}} + \lambda \cdot \mathcal{L}_{\mathrm{anchor}}\)。
  - 锚定损失对干净位置的重构施加额外约束，确保模型在学习纠偏能力的同时不过度修改正常数据，从而在保真性与纠偏性之间取得平衡。

## 2.5 虚假数据防御与状态重构流程 (FDIA Defense and State Reconstruction Workflow)

- 流程概述
  - 本节描述所提方法在电力系统SCADA/EMS环境中的完整防御流程，明确各模块的功能边界与数据接口。
  - **核心流程图**：数据采集 → 检测模块 → 分支判断 → 状态估计/数据重构 → 调度中心（见图Y）。

- 防御流程各阶段

  **阶段一：数据采集与检测 (Detection)**
  - 量测数据 \(\tilde{\mathbf{y}}_t\) 从RTU/PMU实时采集后，首先送入上游FDIA检测模块。
  - 检测模块输出判别结果：若 \(t \notin \mathcal{T}_{\mathrm{att}}\)，则认为数据可信；若 \(t \in \mathcal{T}_{\mathrm{att}}\)，则标记为可疑。
  

  **阶段二：分支处理**
  - **正常分支**：若 \(t \notin \mathcal{T}_{\mathrm{att}}\)，量测 \(\tilde{\mathbf{y}}_t\) 直接送入状态估计模块，执行标准WLS估计。
  - **可疑分支**：若 \(t \in \mathcal{T}_{\mathrm{att}}\)，量测 \(\tilde{\mathbf{y}}_t\) 进入数据重构模块进行恢复处理。

  **阶段三：数据重构 (Recovery)**
  - 对于被标记的时刻 \(t \in \mathcal{T}_{\mathrm{att}}\)，构建历史窗口 \(\mathcal{W}_t = \{\tilde{\mathbf{y}}_\tau\}_{\tau=t-K+1}^{t}\)。
  - 将窗口序列输入2.3节所述框架，因果TCN编码器提取时序特征，经LGSSM先验约束与MLP解码器，输出重构量测 \(\hat{\mathbf{y}}_t\)。
  - 重构量测替代原始可疑数据，进入后续处理流程。

  **阶段四：状态估计与调度 (State Estimation)**
  - 无论来自正常分支的 \(\tilde{\mathbf{y}}_t\) 还是重构分支的 \(\hat{\mathbf{y}}_t\)，均送入WLS状态估计模块。
  - 状态估计输出可信状态 \(\hat{\mathbf{x}}_t\)，作为潮流分析、安全校核与经济调度的统一输入。
  - 最终状态信息传输至调度中心，支撑运行决策。
