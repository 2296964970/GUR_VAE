## FDIA 防御与状态重构流程配图设计（精简版）

目标：保留纵向主链 + 左侧 TCN‑VAE 算法框的结构，用尽量短的标签表达 2.5 节的流程，让图看起来更简洁。

---

### 1. 布局与颜色
- 左：虚线框「TCN‑VAE Recovery Algorithm」。
- 右：自上向下的主流程（Power System → Measurements → FDIA Detection → Decision → WLS → Control Center / EMS）。
- 颜色图例（Legend，可放右下角）：
  - 蓝：normal path & states
  - 红：suspicious measurements / path
  - 绿：reconstructed / trusted measurements & states

---

### 2. 右侧主流程（盒子上的文字）

自上而下：
- `Power System`
- `SCADA/EMS Measurements ỹ_t`
- `FDIA Detection`
- 决策菱形：`Decision: t ∈ T_att?`
  - No 分支箭头文字：`No (normal)` → 连接下一个框
  - Yes 分支箭头文字：`Yes (suspicious)` → 指向左侧虚线框
- `Keep ỹ_t`（正常数据直通）
- `WLS State Estimation`（在进 WLS 的箭头上加小字 `ỹ_t / ŷ_t`）
- `Trusted State Estimation x̂_t`
- `Control Center / EMS`
  - 内部纵向三个小框：`Power Flow Analysis` / `Security Assessment` / `Economic Dispatch`

---

### 3. 左侧虚线算法框（盒子上的文字）

虚线框标题：
- `TCN‑VAE based FDIA Defense / Measurement Recovery`

从左到右：
- 小框：`Input ỹ_t (suspicious)`
- 箭头指向：`Construct W_t`（可在框下小字 `Causal window`）
- 大框：`TCN‑VAE Recovery Core`
  - 第一行：`Causal TCN encoder + LGSSM prior`
  - 第二行：`Decoder p_θ(y_t | z_t)`
- 右侧小框：`Output ŷ_t`
- 箭头从 `Output ŷ_t` 指向右侧 WLS，箭头文字：`Reconstructed measurements ŷ_t = G(ỹ_t)`
- 虚线框底部一行小字：
  - `Provides defended measurements at suspicious times (close to identity on clean data).`

---

### 4. 读者一眼要看到的点
- 检测只给出「可疑时刻」，恢复只对 Yes 分支生效，No 分支直接用 ỹ_t。
- WLS 的输入是 `ỹ_t / ŷ_t` 的混合流，而不是总是重构后的数据。
- TCN‑VAE 作为黑盒：只看得见输入 ỹ_t、历史窗口 W_t、输出 ŷ_t，不展开更细的网络细节。
- 颜色区分：蓝=正常，红=可疑，绿=防御后的可信量测与状态。
