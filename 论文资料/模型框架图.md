线性状态空间先验 VAE 理论模型结构图描述（草稿）

本文在理论层面考虑一个固定长度为 $T$ 的时间窗口 $(x_{1:T}, z_{1:T})$，在该窗口内对潜在状态序列施加线性状态空间先验，并采用 VAE 框架建模生成分布与近似后验。配图设计为一张三层结构图，沿窗口内部的时间轴展开，清晰区分生成模型与推断模型，仅展示改进 VAE 的模型结构，不涉及观测掩码或训练细节。

1. 整体布局

- 横轴为一个固定长度时间窗口内的时间步 $t = 1, \dots, T$。
- 纵向自上而下分为三层：
  - 上层：重构序列与解码器（生成模型的一部分）；
  - 中层：潜在状态序列及其线性状态空间先验（核心创新组件）；
  - 下层：TCN 编码器，对应近似后验 $q_\phi(z_{1:T} \mid x_{1:T})$。
- 图中用颜色区分：
  - 蓝色：生成模型（prior + decoder）；
  - 橙色：推断模型（encoder）。

2. 中层：线性状态空间先验与潜在序列

- 沿时间画一条位于中间高度的圆形节点链：
  - 节点依次标记为 $z_1, z_2, \dots, z_T$；
  - 相邻节点之间用蓝色实线箭头连接：$z_1 \rightarrow z_2 \rightarrow \dots \rightarrow z_T$。
- 用一个灰色虚线矩形包住整条潜在链（从 $z_1$ 到 $z_T$），表示“线性状态空间先验”作用在整个序列 $z_{1:T}$ 上，而不是只作用在某一段；
- 在该虚线框内、靠上方写出先验标题和公式：
  - 粗体说明：Linear state-space prior；
  - 数学形式：
    \[
    z_1 \sim \mathcal{N}(m_0, S_0), \quad
    z_t \mid z_{t-1} \sim \mathcal{N}(A z_{t-1}, Q), \quad t = 2, \dots, T.
    \]
- 在图的一角画一个淡灰虚线框，用于对比标准 VAE 先验：
  - 在虚线框内标注：
    \[
    \text{Standard VAE prior: } z_t \sim \mathcal{N}(0, I)\ \text{(i.i.d. over } t\text{)}.
    \]
  - 用一条灰色虚线从该框指向同一条 $z$ 链，表示本工作用线性状态空间先验替代了传统独立高斯先验。

3. 上层：解码器与重构序列（生成模型）

- 在每个 $z_t$ 的正上方画一个小矩形（或圆角矩形），统一标注为：
  - Decoder $f_\theta$。
- 从每个 $z_t$ 向上画蓝色箭头指向对应的解码器模块，再从解码器模块画箭头指向重构节点 $\hat{x}_t$（即 $z_t \rightarrow f_\theta \rightarrow \hat{x}_t$）。
- 在最上方沿时间画一行方形节点：
  - 依次标记为 $\hat{x}_1, \hat{x}_2, \dots, \hat{x}_T$，表示由解码器生成的重构序列；
-  在三个代表性时间步（$1$、$t$、$T$）对应的箭头旁分别标注条件分布：
    \[
    p_\theta(x_1 \mid z_1),\quad p_\theta(x_t \mid z_t),\quad p_\theta(x_T \mid z_T).
    \]
   其中 $x_t$ 为第 $t$ 个时间步的观测随机变量，$\hat{x}_t$ 为其基于 $z_t$ 的重构值；未显式画出的中间时间步用省略号表示，它们同样服从 $p_\theta(x_t \mid z_t)$ 的形式。
  其中 $x_t$ 是生成模型中的观测随机变量，$\hat{x}_t$ 表示该条件分布的代表性统计量（通常取条件均值），即
    \[
    \hat{x}_t = \mathbb{E}_\theta[x_t \mid z_t],
    \]
  在训练时与底部输入带上的真实观测 $x_t$ 比较。
- 将“上层 + 中层”用一个淡蓝色大框包围，并在框旁标注生成模型（显式区分先验参数与解码器参数）：
  \[
  \text{Generative model: } p_{\theta, \eta}(x_{1:T}, z_{1:T}) 
  = p_\eta(z_1)\prod_{t=2}^T p_\eta(z_t \mid z_{t-1}) \prod_{t=1}^T p_\theta(x_t \mid z_t),
  \]
  其中 $\eta = (m_0, S_0, A, Q)$ 为线性状态空间先验的参数，$\theta$ 为解码器参数。
- 图中不画观测掩码或缺失标记。生成模型中的观测随机变量记为 $x_t$，上层方形节点 $\hat{x}_t$ 为其根据 $z_t$ 的重构（例如条件均值），底部输入带上的 $x_{1:T}$ 则表示同一随机变量在一个窗口上的真实观测样本。

4. 下层：TCN 编码器与近似后验（推断模型）

- 在图的最下方画一条横向长条作为输入带，在长条附近标记为 $x_{1:T}$，视觉上覆盖整个时间轴；
- 从该输入带画一条橙色粗箭头指向上方的 Causal TCN encoder 模块，表示编码器以整个观测序列 $x_{1:T}$ 为输入。
- 在这条输入带上方画一个跨越所有时间步的橙色大矩形模块：
  - 主标题：Causal TCN encoder；
  - 副标题（小字）：$q_\phi(z_{1:T} \mid x_{1:T})$，其中假设时间上的因子分解
    \[
    q_\phi(z_{1:T} \mid x_{1:T}) = \prod_{t=1}^T q_\phi(z_t \mid x_{1:t}),
    \]
    由因果 TCN 保证 $z_t$ 的后验只依赖窗口内的历史观测 $x_{1:t}$。
- 从该编码器模块向上画橙色箭头指向中层每个潜在节点 $z_t$：
  - 如果在图中画出所有时间步，则在每个 $z_t$ 旁边标注对应时间步的后验参数和分布，例如：
    - 在 $z_1$ 附近：
      \[
      (\mu_1, \Sigma_1), \quad q_\phi(z_1 \mid x_1) = \mathcal{N}(z_1; \mu_1, \Sigma_1),
      \]
    - 在 $z_2$ 附近：
      \[
      (\mu_2, \Sigma_2), \quad q_\phi(z_2 \mid x_{1:2}) = \mathcal{N}(z_2; \mu_2, \Sigma_2),
      \]
    - $\dots$
    - 在 $z_T$ 附近：
      \[
      (\mu_T, \Sigma_T), \quad q_\phi(z_T \mid x_{1:T}) = \mathcal{N}(z_T; \mu_T, \Sigma_T).
      \]
    其中 $\mu_t \in \mathbb{R}^{d_z}$ 为第 $t$ 个时间步潜在状态的均值向量，$\Sigma_t \in \mathbb{R}^{d_z \times d_z}$ 为该时间步潜在状态的协方差矩阵。在实现中，编码器直接输出协方差的 Cholesky 因子（下三角矩阵），从而得到一般的对称正定协方差 $\Sigma_t$，而不局限于对角形式。
  - 如果图中只显式展示首、中、尾三个时间步，可以采用同样的记号，只保留 $t=1, t$ 和 $t=T$ 三个节点，中间用省略号连接。
- 用一个淡橙色大框包围下层结构，并标注：
  \[
  \text{Inference model: } q_\phi(z_{1:T} \mid x_{1:T}).
  \]
- 重要的是：图中不画任何从先验块或蓝色模块“喂给”编码器的箭头。先验与编码器都通过同一条潜在链 $z_{1:T}$ 关联，体现“生成模型 vs 近似后验”的分工，而非先验直接作为编码器输入。

5. 图例与图内标题

- 在图的一角加入简洁图例：
  - 蓝色线条 / 模块：Generative model；
  - 橙色线条 / 模块：Inference model；
  - 圆形节点：Latent state $z_t$；
  - 方形节点：Observed variable $x_t$。
- 在图的右上角用一行小字给出图内标题，例如：
  - “Linear state-space prior VAE”。
